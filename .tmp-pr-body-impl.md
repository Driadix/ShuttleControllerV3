# Observability Producer + Sink, UART TX (#72)

Реализация vertical slice по `docs/observability-design-v3.md` (дизайн-артефакт #72, PR #98 merged, двухпроходный review APPROVE + pass-3 re-verify).

## Что реализовано

- **domain/observability.\***: Producer (реализует KernelEvents / RuntimeEvents / safety::Events; envelopes, счётчики single-writer, snapshot ≤ 456 Б / 4 фрагмента, fault-capture staging ≤ 512 Б с supersede, coalesced drop-события 0x05xx) + Sink-политика (очереди telemetry 8 / events 32 / logs 32 / traces 16 + Control 16 / Service 8; drop-политики #43 §6; приоритеты 1..5; per-class caps 128 Б и суммарный бюджет 230 Б/тик; **defer-on-backpressure** — на drain кадр, не поместившийся в cap/бюджет/кольцо, остаётся в очереди, drop только на enqueue).
- **domain/codec.\***: Envelope (два wire-layout: telemetry 10 Б / остальные 14 Б), TelemetryBody (18 Б), EventBody (12 Б), LogBody (текст ≤ 80 Б без chunk-сплита), TraceBodyHeader, TimeValidity, MsgObservability (T16).
- **domain/ports.h**: + `v3::UartPort`, `v3::WallClockSource`, `v3::IdentitySource`; удалены `slice::UartPort`/`slice::ObservabilityPort` (clean cutover, 0 вызовов).
- **adapters/**: `uart_bridge` (USART1 PA9/PA10 230400 8E1, кольцо 256 Б + TXE ISR — только ring→TDR, R2; never-block, obligation #12), `rtc_clock` (read-only RTC, INITS-гейт, BCD→epoch, без HAL-инициализации — #76), `identity` (STM32 UID).
- **platform/**: `observability_schedule` glue (sink_tick каждый тик, telemetry_tick 300 мс bridge default, birth_check), main.cpp wiring — заглушки Фазы 2 заменены Producer/Sink.
- **build flags**: сняты `-D NO_HW_SERIAL` / `-D HAL_UART_MODULE_DISABLED` (решение владельца §0.1, Semantic change #51 §4).
- **bench/verification-runner**: V3-кадр (0xE3 0x10) декодер аддитивно (frameFormat v1|v3), сценарий `observability-uart` (L4, telemetry heartbeat).

## Pass-1 review (ImplReviewPass1 → NOT APPROVE) — исправлено F1-F10

- **F1 (BLOCKING)**: `rearm()` всегда ставил now+1 → telemetry эмитился каждый тик (~1 кГц). Исправлено: rearm принимает период (паттерн sensing_schedule: PRIMARY now+period, FALLBACK now+1); telemetry/birth — 300 мс, sink — каждый тик.
- **F2 (MAJOR)**: boot reset-cause терялся (kernel::init → reset_cause ДО producer.init). Исправлено: Producer/Sink init перенесены ДО kernel::init.
- **F3 (MAJOR)**: Query эхо-уходил в UART (Sink не перехватывал). Исправлено: `Sink::is_query_frame`/`handle_query_frame` — Query маршрутизируется в Producer::answer_query (фрагменты snapshot), Query-кадр никогда не уходит на wire (T9b).
- **F4 (MAJOR)**: tail-зеркала fault-capture копировали префикс canonical-фрейма (sync+header) вместо записей envelope+body. Исправлено: копируется payload с data+10 (T11-проверка доставки сохранена).
- **F5-F10 (MINOR)**: `m_capture_pending` сбрасывается после синхронной доставки (supersede честно считает только для незавершённого захвата, T11 обновлён); `update_uptime` вынесен в public и инкрементится по second-edge из glue; `trigger_tick` = m_now_ms (health_changed/crash_marker_pending/reset_cause); snapshot-секции по `sections_mask` (8 бит); `type_id` u16 (ops-блок); reset_cause ≠ PowerOn триггерит fault-capture.
